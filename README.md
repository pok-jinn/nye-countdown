# New Year's Eve Countdown

A fullscreen New Year's Eve countdown application optimized for Smart TV displays. Built with Next.js 14, Tailwind CSS, Framer Motion, and canvas-confetti.

## Features

- **Fullscreen Design**: Optimized for 1080p and 4K TV screens with no scrolling.
- **Real-time Countdown**: Displays days, hours, minutes, and seconds until January 1st, 2026.
- **Smooth Animations**: Number transitions using Framer Motion.
- **Celebration Effect**: Looping confetti explosion when countdown reaches zero.
- **High Contrast**: Deep dark background with glowing cyan text for TV visibility.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Effects**: canvas-confetti
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Deployment

Deploy on Vercel, Netlify, or any static hosting service.
